# 内置预览窗格设计

> 2026-10-17 · 状态：已实现 · 代码：src/lib/preview.ts、src/components/terminal/{PreviewPane.tsx,previewActions.ts}、src/store/tabStore.ts

## 目标

不打开宿主浏览器，在分屏里直接预览容器内的 Web 服务（左边 Claude 改代码，右边看效果），并解决"Claude 说 localhost:3000，宿主实际要访问 127.0.0.1:3010"的错位。

## 入口

| 入口 | 行为 |
|---|---|
| 状态栏端口、额度浮层端口 | 在当前 Tab 的聚焦终端右侧打开预览；该 Tab 已有同容器预览时复用（只换地址） |
| 终端里的链接 | `localhost` / `127.0.0.1` / `0.0.0.0` / `[::1]` + 端口：按该终端所属容器的端口映射换成宿主地址后在预览打开；无法访问时提示原因（未映射 / 仅监听 127.0.0.1 / 未在监听）；其他链接仍用系统浏览器（OAuth 登录必须在系统浏览器完成） |

## 窗格

- 标题条：刷新、地址栏（可编辑，仅 http/https）、在系统浏览器打开、关闭。
- 内容：iframe（`csp: null`，开发服务一般不发 `X-Frame-Options`）。
- 隐藏 Tab 中保持挂载，切回不丢页面状态。

## 分屏模型

- 预览是分屏树中的特殊叶子：`sessionId = "pv:<n>"`，记录 `{ container, url, nonce }` 存于 tabStore.previews（nonce 用于刷新）。
- 预览叶子**不会成为 activeSessionId**：标题栏、状态栏、快捷键等依赖"当前会话"的逻辑不变。
- 焦点循环（`neighbor`）跳过预览叶子。
- 关闭 Tab 时只对终端叶子调用 closeSession；Tab 内终端全部移除后，剩余预览一并移除，Tab 关闭。
- 布局不持久化（与终端一致）。

## 已知限制

- 无前进 / 后退：跨源 iframe 的历史不可由外层控制。
- 发送 `X-Frame-Options` / `frame-ancestors` 的站点无法显示 → 用"在系统浏览器打开"。
- 焦点在 iframe 内时应用快捷键不生效（点一下终端恢复）。

## 不做

弹出独立窗口、访问未映射的容器端口、把端口映射告知容器内 Claude。

## 测试

- 单测：链接转换（本机主机名、已映射 / 未映射 / 仅监听回环 / 未在监听 / 外部链接、保留路径与查询串）；分屏树（打开、复用、关闭、焦点跳过预览、终端清空时清理预览）。
- tsc；真机：`claude-dev-01` 打开 `:3010` 预览。
