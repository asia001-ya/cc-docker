# Stitch 状态栏设计落地

视觉方案基于 Stitch 状态栏原型，采用紧凑半宽刻度与四段色彩，更新于 2026-10-18。以下保留最终颜色与尺寸说明；私有项目链接和屏幕标识不随源码发布。

实现位于 `docker/rootfs/opt/tdc/statusline-display.mjs`，浏览器预览和容器采集脚本共用同一渲染函数。

## 排版

六个字段依次为模型、思考级别、上下文容量、Git 分支、末级目录名、上下文占用。默认单行，以暗色 ` · ` 分隔；只有空间不足时按字段换行，长值按显示列截断。

不显示会话名，不添加“思考”“目录”“会话”前缀。目录只显示最后一层文件夹名，采用橙色。模型采用青色底标，级别为淡紫色，容量直接显示真实 `1M` 或 `200K`。

上下文为 `ctx [填充与斜纹] 百分比`：灰色方括号、居中的实心前景字符 `■`、暗色 ASCII 反斜杠余量。相较早期 `▇`，填充高度缩小约三分之一；2026-10-19 根据用户反馈将底部对齐的 `▅` 换为居中字形，解决偏下的问题。由于 ANSI 字符高度离散，尺寸为近似值。刻度长度在上一版自适应长度基础上减半并取最近整数，最少 1 格、最多 16 格，宽窄窗口同步缩短。字号与行距不变，不使用整格背景填充。

## 颜色

| 用途 | 色值 |
| --- | --- |
| 模型 / 模型底色 | `#60CDFF` / `#1B2B38` |
| 思考级别 | `#A78BFA` |
| 目录 | `#FFA657` |
| 上下文 ≤20% | `#16C55D` 绿色 |
| 上下文 >20% 且 ≤50% | `#FFA657` 橙色 |
| 上下文 >50% 且 ≤70% | `#A78BFA` 紫色 |
| 上下文 >70% | `#F85149` 红色 |
| 字段值 | `#E6EDF3` |
| 标签、方括号和未知值 | `#8B949E` |
| 空余斜纹 | `#282D35` |

填充与百分比同步变色，按未经取整的实际占用判断区间；未知占用保留暗色刻度，数值显示 `—`。颜色只表示上下文占用。

## 预览与验证

开发页面 `/tests/statusline.html` 使用实际 xterm 渲染，提供 20% 绿色、40% 橙色、60% 紫色、92% 红色、未知和关闭思考六种合成状态，以及自适应、80 列和 48 列预览。Vite 监听 Docker 源文件，使共享渲染函数的变更能及时刷新。

验证覆盖六字段、上下文容量、未知数值、中文/emoji 宽度、控制字符过滤、Git 读取与状态采集；额外核验 20%、50%、70% 颜色边界以及宽窄窗口的减半尺寸。容器更新通过 `scripts/update-statusline.mjs` 执行，保留旧脚本备份，Claude 原生模式提示由 Claude 继续绘制。

实现效果可通过 `/tests/statusline.html` 预览，验证截图仅在本地保存。
