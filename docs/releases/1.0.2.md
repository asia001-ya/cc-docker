# V1.0.2

Windows x64 更新版本，程序内部版本号为 `1.0.2`，Git 标签为 `v1.0.2`。

## 更新与修复

- 主页面新增“释放内存”，回收本机 Docker Desktop WSL2 的可回收缓存，保留运行中的容器、终端会话和进程。结果分别显示 WSL 缓存变化及 Windows `VmmemWSL` 前后占用，避免把缓存减少误报为 Windows 已释放同等内存。
- 内存回收结果中可进一步选择“整理空闲页”，帮助 WSL 归还零散空闲内存。两种操作共用执行限制和 30 秒冷却；缓存回收后观察约 15 秒，空闲页整理后观察约 30 秒。整理期间可能短暂变慢，Windows 占用是否下降取决于当前负载及 WSL 回收情况。
- 新会话默认使用目标容器的 Docker `WorkingDir`；未配置时使用 `/`。侧栏快速新建和授权终端采用同一规则，手动选择或从历史恢复的路径不会被延迟返回的默认值覆盖。
- 容器侧栏和额度总览统一使用进度条、重置倒计时及额度数据刷新时间。侧栏默认加宽至 380px，可拖动边缘调整并记住宽度；窄窗口下内容自动换行。
- 移除侧栏、额度总览及底部状态栏中可能与 Claude 当前模型不一致的模型名称。
- “输出内容”收起时显示为文档图标。分屏时位于当前窗格标题下方，避免遮挡关闭按钮；阅读面板随窗格宽高适配，按 Esc 返回图标。

## 下载与运行

- `cc-docker-1.0.2-windows-x64-setup.exe`：Windows 安装包。
- `cc-docker-1.0.2-windows-x64.exe`：可直接运行的程序，配置仍保存到用户应用数据目录。
- `SHA256SUMS.txt`：下载文件的 SHA256 校验值。

需要 Docker Desktop（WSL2 / Linux 容器模式）和 Microsoft Edge WebView2 Runtime。编译文件不包含 Docker 镜像、账号或个人配置。请退出旧版桌面程序后安装或运行新版；已有 tmux 会话可重新附着。

## 验证

前端单元测试、输出阅读器测试、打包隐私测试、Rust 单元测试、Clippy 和 Windows 生产打包通过。默认目录及其异步返回、侧栏宽度与窄布局、分屏关闭按钮和输出图标已完成浏览器验证。内存操作已在本机 Docker Desktop WSL2 验证，容器和会话保持运行；缓存变化和 Windows 占用分别报告，不承诺固定释放量。
