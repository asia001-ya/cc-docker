# V1.0.1

Windows x64 修复版本，程序内部版本号为 `1.0.1`，Git 标签为 `v1.0.1`。

## 修复

- 修复额度提前预警被误判为耗尽、导致会话名前状态点变红的问题。终端文本仅在明确达到上限时触发耗尽；旧版默认识别规则自动迁移，自定义规则保留。
- 修复底部账号额度条的填充和空余斜纹高度不一致，统一为固定尺寸。
- 内置状态栏小字体，使 Claude 终端上下文条的实心格与短斜纹共享高度和基线；终端在字体加载后附着会话，避免缓存回退字形。

## 下载与运行

- `cc-docker-1.0.1-windows-x64-setup.exe`：Windows 安装包。
- `cc-docker-1.0.1-windows-x64.exe`：可直接运行的程序，配置仍保存到用户应用数据目录。
- `SHA256SUMS.txt`：下载文件的 SHA256 校验值。

需要 Docker Desktop（WSL2 / Linux 容器模式）和 Microsoft Edge WebView2 Runtime。编译文件不包含 Docker 镜像、账号或个人配置。请退出旧版桌面程序后安装或运行新版；已有 tmux 会话可重新附着。

## 验证

前端、Rust、容器脚本测试、Clippy、生产构建与打包隐私检查通过。额度预警误判和旧默认规则迁移已由回归测试覆盖；用户现场的会话切换过程尚未完整复现验证。
