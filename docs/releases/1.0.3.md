# V1.0.3

Windows x64 更新版本，程序内部版本号为 `1.0.3`，Git 标签为 `v1.0.3`。

## 更新与修复

- “释放内存”升级为整机内存管理面板，显示 Windows 物理内存总量、已用量、可用量、提交量及可搜索的进程占用排行。Docker 未连接时也能分析和整理普通应用。
- 应用默认不勾选，可手动选择或全选当前可整理项，再一键整理工作集；可选同时回收 WSL 缓存，保留独立的 WSL 缓存回收和空闲页整理操作。
- 后端重新核对进程用户、会话、权限、PID 与创建时间，跳过系统关键、受保护、提权、桌面 Shell、本应用及 Docker/WSL/虚拟化进程；权限不足或进程退出逐项报告。
- 结果分别显示整机可用内存、应用工作集、WSL 缓存和 VmmemWSL 的前后变化，不将这些数字相加作为释放量。清理后重新分析，关闭重开面板保留任务、结果和操作错误；所有清理共用并发限制及完成后 30 秒冷却。
- 新增“设置 → 应用更新”，默认启动后及每六小时检查 GitHub 稳定版本，自动下载、校验并在正常退出后安装；支持安装版和独立运行版，也可手动“更新并重启”。更新设置可单独关闭，保留个人配置、Docker 容器及已有 tmux 会话。
- 发布包只含公共构建输出，新增版本一致性检查和独立打包脚本，生成安装包、独立运行程序及 SHA256 校验清单。

## 下载与运行

- `cc-docker-1.0.3-windows-x64-setup.exe`：Windows 安装包。
- `cc-docker-1.0.3-windows-x64.exe`：可直接运行的程序，配置仍保存到用户应用数据目录。
- `SHA256SUMS.txt`：下载文件的 SHA256 校验值。

需要 Docker Desktop（WSL2 / Linux 容器模式）和 Microsoft Edge WebView2 Runtime。请退出旧版桌面程序后安装或运行新版。V1.0.2 没有应用自动更新入口，首次升级到 V1.0.3 需手动下载。

工作集整理保留进程和私有内存分配，但重新读取页面时可能短暂变慢、占用回升，不能修复内存泄漏。普通应用整理后观察约 5 秒，包含 WSL 缓存时约 15 秒，WSL 空闲页整理约 30 秒；不保证固定降幅，不提权、不关闭应用、不清空 Windows 待机缓存。

## 验证

前端测试、类型检查、打包隐私测试、发布打包脚本测试、Rust 单元测试与 Clippy 已通过。专用 64 MiB 测试进程完成实际工作集整理，确认进程、私有分配与数据保持完整，退出后读数标为不可用；普通应用分析已验证不依赖 Docker 连接。面板浏览器预览已验证，完整桌面交互及跨版本自动安装仍需后续实际使用验证。
