# 输出内容目录与阅读面板

终端右上角的文档图标可展开「输出内容」，列出当前聚焦会话生成或更新的计划、实现类 Markdown 文件。点击条目右侧箭头，展开独立阅读面板；点击目录标题可收起为图标。分屏时，图标和阅读面板跟随聚焦的终端，位于窗格标题下方，不遮挡关闭按钮。

- 正文支持标题、列表、表格、代码块和文本选择，表格与代码可横向滚动。
- 顶部可搜索标题、切换内容、刷新和复制 Markdown；点击关闭按钮或按 Esc 返回文档图标。
- 新文档到来时保留正在阅读的内容，提供「查看最新输出」入口。
- 各个文档的滚动位置、面板开关状态在当前应用运行期间保留，切换终端后可以继续阅读；缓存最多保留 12 个终端。退出应用后不保留阅读位置。
- 面板覆盖在终端右侧，打开、关闭均不改变终端宽高，不触发 Claude 的尺寸重绘；窄窗格下搜索栏和页脚自动换行，正文可滚动；全屏模式仍可继续使用。

## 内容来源与兼容性

桌面端根据终端 ID 和容器 statusline 保存的会话映射，从 Claude 的原始 JSONL 记录提取 Markdown 文件快照。因此不会带入终端 ANSI 控制序列或重绘产生的重复历史，也不会写入或修改会话记录。旧镜像无需重建，读取程序由桌面端携带；容器需有 Node.js 和本项目的 statusline 会话映射。显式 `--resume` 会话也支持按恢复 ID 查找。

目录只收录主会话当前分支的 Markdown `Write` 文件、随后 `Edit` 更新，以及带明确 `.md` 文件路径和正文的 `ExitPlanMode` 结果。同一文件按路径去重，阅读面板显示其路径。普通回答、回答中的 Markdown 标题、没有文件路径的内联计划、思考过程、一般工具结果和子代理会话均不加入目录。只存在于文件系统、没有在会话记录中保存正文的文件暂不读取；没有生成文档时显示空目录。

仅当前聚焦终端每 3 秒检查一次，页面不可见时暂停。记录没有变化时不重复传输正文。每次最多扫描记录末尾 16 MiB、显示最近 40 项，单项上限 256 Ki UTF-16 字符，总正文上限 2 MiB；达到上限会在面板中提示，因此「复制 Markdown」复制的是当前可读取范围。

正文忽略 HTML，不加载远程图片；仅用户点击的 HTTP(S) 链接通过系统浏览器打开。前端接口只接受已保存的终端 ID，不接受任意文件路径；后端将实际读取路径限制在 Claude 的 `projects` 目录内。

## 验证

```powershell
npm test
npm run test:outputs
npm run test:docker
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run tauri -- build --no-bundle
```

开发服务器下打开 `/tests/output-reader.html` 可验证合成长计划、中文表格、代码、标题搜索、新输出提示与位置保留。该页面使用测试数据，不读取真实会话，也不进入生产入口。

2026-10-18 验证结果：前端 101 项、输出解析 8 项、容器脚本 76 项、Rust 181 项通过；7 项容器测试因 Windows 环境限制跳过，4 项需要外部环境的 Rust 测试默认忽略。浏览器实测确认新增输出前后正文 `scrollTop` 均为 397.20，切换文档、关闭后重开、切换终端后返回均恢复该位置；搜索、复制 Markdown、Esc 关闭、目录折叠通过。另一测试会话仅显示自己的文档，正文不生成图片或脚本元素，控制台无警告或错误。新增回归确认普通回答（包括带实施计划标题的 Markdown 回答）、无文件路径的内联计划和非 Markdown 文件均不进入目录；同一路径的写入、编辑和计划结果合并为一项。

浮动目录与右侧阅读面板可通过 `/tests/output-reader.html` 预览，验证截图仅在本地保存。

相关实现：`src/components/terminal/OutputReader.tsx`、`src/lib/outputReader.ts`、`src-tauri/src/commands/output_cmds.rs`、`src-tauri/src/terminal/output-reader.mjs`。终端重绘问题的原因和修复见 [终端渲染排查](08-terminal-rendering.md)。
